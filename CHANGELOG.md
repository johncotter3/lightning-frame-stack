## [0.1.0] - 2026-07-30

### Added

- Exposure-normalized lightning extraction for GIF and video inputs.
- ECC-based translation, Euclidean, and affine stabilization.
- Automatic clean-base-frame selection.
- Traditional normalized maximum-stack mode.
- Sensor-flare and rolling-shutter artifact rejection.
- Installable command-line interface and reusable Python API.
- Synthetic demo, automated tests, and GitHub Actions CI.
