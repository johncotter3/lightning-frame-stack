# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Please do not publish exploit details, private footage, or location-identifying
media in a public issue.

Use GitHub's **Report a vulnerability** link on the repository's Security page
to submit a private report. Include:

- the affected version or commit;
- reproduction steps or a minimal synthetic test file;
- expected and observed behavior;
- any known mitigations.

If private vulnerability reporting is temporarily unavailable, open a public
issue titled `Security contact requested` without technical details or private
media. A maintainer can then establish a private channel.
